# 三顾襄阳 · AR 文化奇遇

以原创人物 IP 为主角的毕业设计作品，将襄阳隆中文化、三顾故事和手机网页 AR 体验结合起来。

发布后的首页：https://mcbrienanuel193-svg.github.io/sangu-xiangyang-ar/

扫码 / AR 入口：https://mcbrienanuel193-svg.github.io/sangu-xiangyang-ar/ar.html

## 怎么体验

1. 在电脑上打开网站的可打印展示卡，或将 poster.html 打印为 A4。
2. 用手机扫描二维码，在系统浏览器中打开网页。
3. 点击开启摄像头，允许镜头访问，再对准完整 Hiro 黑白方框。
4. 切换刘备、诸葛亮、关羽、张飞，调整人物大小、收听对白并保存合影。
5. 回到三顾之旅，体验三段故事，收集诚、礼、智印记。

二维码负责打开网页，黑白方框负责 AR 追踪。角色采用透明人物纸偶与展示卡空间定位，属于 2.5D 展示，不包含完整三维角色模型或骨骼动画。

## 程序结构

- index.html、app.css、app.js：故事互动、人物图鉴和本地印记。
- ar.html、ar.css、ar-app.js：镜头、展示卡追踪、人物动画与合影。
- poster.html：可打印 A4 展示卡。
- entry-qr.js：按当前网站地址生成入口二维码，支持仓库子目录。
- assets：原始 IP、透明衍生人物、识别图与相机参数。
- vendor：本地保存的 A-Frame、AR.js、二维码库与许可证。

网站无需数据库。印记保存在当前浏览器本地。镜头画面与合影由设备处理，程序没有上传摄像头画面的逻辑。语音由设备提供。

## 部署与验证

GitHub Pages 使用 main 分支的仓库根目录，并保留 .nojekyll。手机 AR 使用 HTTPS 地址。

已检查故事流程、印记保存、人物切换、竖屏布局、摄像头拒绝提示，以及模拟摄像头下的真实识别和合影。仓库子路径下的首页、AR 入口、打印卡和二维码已验证。真实手机访问和相机效果需在展览使用的网络、灯光与打印卡下实测。

四张人物原画由创作者提供；透明人物图为依据原画制作的衍生展示素材。故事对白与诚、礼、智任务为原创设计，不作为历史原文。第三方代码和素材来源见 THIRD_PARTY.md。
